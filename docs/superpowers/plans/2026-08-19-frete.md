# Frete (Melhor Envio) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O cliente informa o CEP no carrinho e recebe as opções reais de frete (transportadora, prazo e preço) vindas do Melhor Envio, com frete grátis aplicado automaticamente acima do valor configurado. O dono da loja configura o CEP de origem, as dimensões da embalagem e o peso de cada variação pelo admin.

**Architecture:** O peso vive em `ProductVariation` (tamanho influencia peso), com sugestão automática vinda de um padrão por categoria. As dimensões da embalagem e o CEP de origem vivem em `StoreSettings`, editáveis numa página nova de configurações do admin. A cotação é uma Server Action pública que monta o payload a partir dos dados **do banco** (nunca do cliente — o cliente só manda o CEP), chama a API do Melhor Envio e devolve as opções normalizadas.

**Tech Stack:** Next.js 16 (App Router, Server Actions), Prisma 7, API REST do Melhor Envio

**Spec:** `docs/superpowers/specs/2026-08-18-ecommerce-v1-design.md`

## Pré-requisito manual (bloqueia as Tasks 5 e 6, não as anteriores)

Antes da Task 5 é preciso ter:
1. **Conta no Melhor Envio** (https://melhorenvio.com.br) e um **token de API** gerado em Configurações → Tokens. Existe ambiente sandbox (`sandbox.melhorenvio.com.br`) com token próprio — usar sandbox no desenvolvimento.
2. **CEP de origem** — de onde as encomendas saem.

Tasks 1-4 não dependem disso e podem ser feitas antes.

## Escopo: o que NÃO entra

- **Geração de etiqueta / compra do frete** — isso é do plano de pedidos no admin, depois do checkout existir.
- **Rastreamento** — mesmo motivo.
- **Escolha do frete no checkout** — esta plano entrega a cotação no carrinho; persistir a escolha junto do pedido é do plano de checkout.

## Global Constraints

- Sempre usar o singleton `src/lib/prisma.ts`, nunca instanciar `PrismaClient`.
- **Toda rota pública nova precisa de `export const dynamic = "force-dynamic";`** — sem isso o Next.js 16 congela a página no build (já aconteceu neste projeto).
- **Toda Server Action de mutação no admin precisa chamar `await requireAdmin()` como primeira linha** (de `src/lib/require-admin.ts`). Actions públicas da loja NÃO chamam.
- **O cliente só fornece o CEP de destino.** Peso, dimensões, valor segurado e CEP de origem vêm todos do banco. Nunca aceitar peso/preço/dimensão vindos do navegador — a cotação define quanto o cliente paga de frete.
- Dinheiro em centavos internamente. A API do Melhor Envio trabalha com **reais em string** (ex: `"19.80"`) e **peso em quilos** (ex: `0.3`) — a conversão fica isolada no cliente da API, e nada além dele manipula essas unidades.
- Peso é guardado em **gramas** (`Int`) no banco, nunca float.
- **O token do Melhor Envio é segredo** — só em `.env`, nunca commitado, nunca enviado ao cliente, nunca logado.
- **Nunca criar nem commitar `.env.example`.**
- `AGENTS.md` na raiz e `node_modules/next/dist/docs/` são **reais** — não descartar como ruído se algo não compilar.

- [ ] **Step 1: Criar a Server Action**

Create `src/app/admin/configuracoes/actions.ts`:
```typescript
"use server";

import { prisma } from "@/lib/prisma";
import { requireAdmin } from "@/lib/require-admin";
import { parsePriceToCents } from "@/lib/money";
import { revalidatePath } from "next/cache";

export type SettingsActionState = { error?: string; ok?: boolean } | undefined;

function parsePositiveInt(value: FormDataEntryValue | null, min: number): number | null {
  const parsed = Number(String(value ?? "").trim());
  if (!Number.isFinite(parsed) || !Number.isInteger(parsed) || parsed < min) {
    return null;
  }
  return parsed;
}

export async function updateSettings(
  _prevState: SettingsActionState,
  formData: FormData
): Promise<SettingsActionState> {
  await requireAdmin();

  const freeShippingCents = parsePriceToCents(String(formData.get("freeShipping") ?? ""));
  if (freeShippingCents === null) {
    return { error: "Valor de frete grátis inválido" };
  }

  const pixDiscountPercent = parsePositiveInt(formData.get("pixDiscount"), 0);
  if (pixDiscountPercent === null || pixDiscountPercent > 100) {
    return { error: "Desconto do Pix deve ser um número entre 0 e 100" };
  }

  const maxInstallments = parsePositiveInt(formData.get("maxInstallments"), 1);
  if (maxInstallments === null || maxInstallments > 24) {
    return { error: "Parcelas deve ser um número entre 1 e 24" };
  }

  const packageWidthCm = parsePositiveInt(formData.get("packageWidth"), 1);
  const packageHeightCm = parsePositiveInt(formData.get("packageHeight"), 1);
  const packageLengthCm = parsePositiveInt(formData.get("packageLength"), 1);
  if (packageWidthCm === null || packageHeightCm === null || packageLengthCm === null) {
    return { error: "Dimensões da embalagem devem ser números inteiros em centímetros" };
  }

  const defaultWeightGrams = parsePositiveInt(formData.get("defaultWeight"), 1);
  if (defaultWeightGrams === null) {
    return { error: "Peso padrão deve ser um número inteiro em gramas" };
  }

  const rawZip = String(formData.get("originZipCode") ?? "").replace(/\D/g, "");
  if (rawZip.length !== 8) {
    return { error: "CEP de origem deve ter 8 dígitos" };
  }

  await prisma.storeSettings.update({
    where: { id: 1 },
    data: {
      freeShippingCents,
      pixDiscountPercent,
      maxInstallments,
      packageWidthCm,
      packageHeightCm,
      packageLengthCm,
      defaultWeightGrams,
      originZipCode: rawZip,
    },
  });

  revalidatePath("/admin/configuracoes");
  revalidatePath("/");
  revalidatePath("/carrinho");
  return { ok: true };
}
```

### Task 5: Cliente da API do Melhor Envio

**Files:**
- Create: `src/lib/melhor-envio.ts`
- Test: `src/lib/melhor-envio.test.ts`

**Interfaces:**
- Produces: `type ShippingQuote = { id: number; name: string; company: string; priceCents: number; deliveryDays: number }`, `type ShippingQuoteInput = { originZipCode: string; destinationZipCode: string; packageCm: { width: number; height: number; length: number }; weightGrams: number; insuranceCents: number }`, `quoteShipping(input: ShippingQuoteInput): Promise<ShippingQuote[]>`, e as funções puras `buildQuotePayload(input)` e `parseQuoteResponse(raw: unknown): ShippingQuote[]`

**Pré-requisito:** o token do Melhor Envio precisa estar no `.env` antes desta task (ver "Pré-requisito manual" no topo).

Detalhes confirmados na documentação oficial da API:
- Endpoint: `POST {base}/api/v2/me/shipment/calculate` — base `https://sandbox.melhorenvio.com.br` (desenvolvimento) ou `https://melhorenvio.com.br` (produção)
- Headers obrigatórios: `Authorization: Bearer <token>`, `Accept: application/json`, `Content-Type: application/json`, e **`User-Agent` identificando a aplicação com email de contato** (obrigatório, a API rejeita sem ele)
- Peso vai em **quilos** (`0.3`), dimensões em **centímetros**, valor segurado em **reais com duas casas** (`"129.90"`)
- A resposta é um array; **usar `custom_price` e `custom_delivery_time`** (refletem as customizações da conta), não `price`/`delivery_time`
- Opções que a transportadora não atende vêm com um campo `error` — devem ser descartadas

```typescript
export type ShippingQuote = {
  id: number;
  name: string;
  company: string;
  priceCents: number;
  deliveryDays: number;
};

export type ShippingQuoteInput = {
  originZipCode: string;
  destinationZipCode: string;
  packageCm: { width: number; height: number; length: number };
  weightGrams: number;
  insuranceCents: number;
};

type QuotePayload = {
  from: { postal_code: string };
  to: { postal_code: string };
  package: { width: number; height: number; length: number; weight: number };
  options: { insurance_value: string; receipt: boolean; own_hand: boolean };
};

function onlyDigits(value: string): string {
  return value.replace(/\D/g, "");
}

export function buildQuotePayload(input: ShippingQuoteInput): QuotePayload {
  return {
    from: { postal_code: onlyDigits(input.originZipCode) },
    to: { postal_code: onlyDigits(input.destinationZipCode) },
    package: {
      width: input.packageCm.width,
      height: input.packageCm.height,
      length: input.packageCm.length,
      weight: input.weightGrams / 1000,
    },
    options: {
      insurance_value: (input.insuranceCents / 100).toFixed(2),
      receipt: false,
      own_hand: false,
    },
  };
}

export function parseQuoteResponse(raw: unknown): ShippingQuote[] {
  if (!Array.isArray(raw)) {
    return [];
  }

  const quotes: ShippingQuote[] = [];
  for (const option of raw) {
    if (typeof option !== "object" || option === null) {
      continue;
    }
    const candidate = option as Record<string, unknown>;
    if (candidate.error) {
      continue;
    }

    const priceReais = Number(candidate.custom_price ?? candidate.price);
    if (!Number.isFinite(priceReais) || priceReais <= 0) {
      continue;
    }

    const deliveryDays = Number(candidate.custom_delivery_time ?? candidate.delivery_time);
    const company = candidate.company as { name?: unknown } | undefined;

    quotes.push({
      id: Number(candidate.id),
      name: String(candidate.name ?? ""),
      company: typeof company?.name === "string" ? company.name : "",
      priceCents: Math.round(priceReais * 100),
      deliveryDays: Number.isFinite(deliveryDays) ? deliveryDays : 0,
    });
  }

  return quotes.sort((a, b) => a.priceCents - b.priceCents);
}

export async function quoteShipping(input: ShippingQuoteInput): Promise<ShippingQuote[]> {
  const token = process.env.MELHOR_ENVIO_TOKEN;
  const baseUrl = process.env.MELHOR_ENVIO_BASE_URL;
  const userAgent = process.env.MELHOR_ENVIO_USER_AGENT;

  if (!token || !baseUrl || !userAgent) {
    throw new Error("Melhor Envio não está configurado");
  }

  const response = await fetch(`${baseUrl}/api/v2/me/shipment/calculate`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${token}`,
      Accept: "application/json",
      "Content-Type": "application/json",
      "User-Agent": userAgent,
    },
    body: JSON.stringify(buildQuotePayload(input)),
  });

  if (!response.ok) {
    throw new Error(`Melhor Envio respondeu ${response.status}`);
  }

  return parseQuoteResponse(await response.json());
}
```

```typescript
"use server";

import { prisma } from "@/lib/prisma";
import { getPublicVariations } from "@/lib/catalog";
import { aggregateRequestedQuantities, resolveQuantity, type CartLine } from "@/lib/cart";
import { quoteShipping, type ShippingQuote } from "@/lib/melhor-envio";

export type ShippingResult = {
  options: ShippingQuote[];
  freeShipping: boolean;
  error?: string;
};

export async function calculateShipping(
  destinationZipCode: string,
  lines: CartLine[]
): Promise<ShippingResult> {
  const zip = String(destinationZipCode ?? "").replace(/\D/g, "");
  if (zip.length !== 8) {
    return { options: [], freeShipping: false, error: "CEP inválido" };
  }

  const settings = await prisma.storeSettings.findUnique({ where: { id: 1 } });
  if (!settings?.originZipCode) {
    return { options: [], freeShipping: false, error: "Loja sem CEP de origem configurado" };
  }

  const requestedByVariation = aggregateRequestedQuantities(lines);
  const variations = await getPublicVariations([...requestedByVariation.keys()]);
  const byId = new Map(variations.map((v) => [v.id, v]));

  let totalWeightGrams = 0;
  let totalCents = 0;
  for (const [variationId, rawQuantity] of requestedByVariation) {
    const variation = byId.get(variationId);
    if (!variation) {
      continue;
    }
    const resolved = resolveQuantity(rawQuantity, variation.stock);
    if (!resolved) {
      continue;
    }
    totalWeightGrams += variation.weightGrams * resolved.quantity;
    totalCents += variation.priceCents * resolved.quantity;
  }

  if (totalWeightGrams === 0) {
    return { options: [], freeShipping: false, error: "Carrinho vazio" };
  }

  const freeShipping = totalCents >= settings.freeShippingCents;

  try {
    const options = await quoteShipping({
      originZipCode: settings.originZipCode,
      destinationZipCode: zip,
      packageCm: {
        width: settings.packageWidthCm,
        height: settings.packageHeightCm,
        length: settings.packageLengthCm,
      },
      weightGrams: totalWeightGrams,
      insuranceCents: totalCents,
    });

    if (options.length === 0) {
      return { options: [], freeShipping, error: "Nenhuma transportadora atende esse CEP" };
    }

    return { options, freeShipping };
  } catch {
    return { options: [], freeShipping, error: "Não foi possível calcular o frete agora. Tente novamente." };
  }
}
```

Nota: `freeShipping` é decidido **no servidor** comparando o subtotal recalculado com `settings.freeShippingCents` — nunca com um valor vindo do cliente. As opções continuam sendo mostradas quando há frete grátis (o cliente ainda escolhe a transportadora/prazo), só o preço é exibido como grátis.
